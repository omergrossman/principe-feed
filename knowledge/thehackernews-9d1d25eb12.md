Critical Langflow and Rails Vulnerabilities Exploited in Active Attacks

Threat actors are actively exploiting critical vulnerabilities in Langflow and Ruby on Rails to conduct credential harvesting and command-and-control operations. CVE-2026-0768 in Langflow (CVSS 9.8) permits arbitrary Python code execution with root privileges through insufficient input validation, while a separate Rails flaw is being weaponized in coordinated campaigns.
