Rockwell Automation 1718-AENTR/1719-AENTR Denial-of-Service Vulnerability

A denial-of-service vulnerability (CVE-2026-9140, CVSS 7.5) affects Rockwell Automation industrial I/O devices due to improper handling of UDP network storms, causing device overload and communication loss requiring power cycles to recover. Rockwell Automation has released version 3.012 as a fix; affected users unable to upgrade should implement network segmentation and access controls per vendor security guidance.
