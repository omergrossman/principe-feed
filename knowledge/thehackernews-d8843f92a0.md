Critical Splunk Enterprise Vulnerability Enables Unauthenticated Remote Code Execution

Splunk has patched a critical vulnerability (CVE-2026-20253, CVSS 9.8) in Enterprise versions prior to 10.2.4 and 10.0.7 that permits unauthenticated attackers to perform arbitrary file operations and execute remote code. Organizations running affected versions should prioritize deployment of available security updates.
