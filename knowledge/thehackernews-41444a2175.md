Squidbleed: 29-Year-Old Squid Proxy Vulnerability Enables HTTP Request Leakage

A heap over-read vulnerability in Squid web proxy, originating from 1997 FTP-parsing logic, allows authenticated proxy users to leak cleartext HTTP requests from other users, potentially exposing credentials and session tokens. The flaw persists in default Squid configurations and was disclosed by Calif.io researchers in June.
