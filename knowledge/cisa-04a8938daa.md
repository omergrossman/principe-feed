ABB Advant Master Online Builder DLL Search Path Vulnerability

CISA published an advisory on CVE-2025-13162 affecting ABB Advant Master Online Builder and Control Builder A, where improper DLL search path handling could allow local code execution if an attacker gains system access. ABB has released patched versions (Control Builder A 1.4/5+, 800xA 6.1.1-5+, 6.2.0-3+) and recommends immediate updates; exploitation requires local access and user interaction.
