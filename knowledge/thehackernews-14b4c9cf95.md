Ruby Patches Regex Engine Vulnerabilities Affecting GitLab RCE Flaws

Ruby released patched versions addressing three bugs in the Onigmo regex engine that underlay four critical remote code execution vulnerabilities in GitLab. Maliciously crafted regex patterns could corrupt memory during compilation, enabling arbitrary code execution. The fixes span Ruby versions 3.3.13, 3.4.12, and 4.0.9.
