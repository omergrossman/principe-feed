Runtime Cloud Security in 2025 - Cloud Application Detection & Response (CADR) Framework

Cloud Native Application Protection Platforms (CNAPPs) have failed to deliver adequate runtime protection for cloud applications, treating them as an afterthought rather than building detection systems from the ground up. Current tools struggle with multi-layer attack detection: vulnerability scanning identifies known issues slowly, workload-layer EDR agents produce low-context alerts requiring coordination with development teams, and cloud-layer anomaly detection often goes unnoticed when legitimate workloads access storage. The MoveIT SQL injection attack illustrates the gap—only Application Detection & Response (ADR) tools could have provided timely blocking, yet even ADR misses post-exploitation behaviors across workload and cloud layers. A new category, Cloud Application Detection & Response (CADR), is proposed to unify visibility across application, workload, and cloud layers, enabling security teams to detect attack chains that span multiple infrastructure components, as seen in XZ Utils, Log4j, Spring4Shell, and other recent breaches.
