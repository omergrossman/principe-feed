DirtyClone Linux Kernel Vulnerability Enables Local Privilege Escalation

JFrog Security Research disclosed a Linux kernel privilege escalation flaw (CVE-2026-43503, CVSS 8.8) that allows local users to achieve root access by manipulating cloned network packets to corrupt file-backed memory. The vulnerability, part of the DirtyFrag family, was demonstrated publicly through a working exploit on June 25.
