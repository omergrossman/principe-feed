Symlink Vulnerabilities in AI Coding Assistants Enable Code Execution

Researchers at Wiz identified a symlink-based vulnerability affecting six AI coding assistants (Amazon Q Developer, Claude Code, Augment, Cursor, Google Antigravity, and Windsurf) that allows malicious repositories to redirect file write operations to sensitive locations without user awareness. The flaw exploits the tools' permission model by requesting access to innocuous files while actually modifying critical system or project files, potentially granting attackers code execution on developer machines.
