ClickFix Campaign Leverages Siemens Software Center DLL Sideloading Vulnerability

Siemens patched a high-severity DLL sideloading flaw (CVE-2026-110936, CVSS 8.4) in Siemens Software Center that has been actively exploited by ClickFix threat actors to deploy remote access trojans. The vulnerability allows attackers to place malicious DLLs in application search directories, achieving code execution with application-level privileges.
