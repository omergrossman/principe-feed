Compromised ConnectWise Credential Used to Access 173 Microsoft 365 Tenants

Threat actors exploited a compromised Microsoft 365 credential associated with ConnectWise Cloud Backup to gain unauthorized access to at least 173 customer M365 environments. The credential, belonging to the backup service used by managed service providers, provided attackers with broad tenant access. Organizations using ConnectWise Cloud Backup are advised to review access logs and credential security posture.
