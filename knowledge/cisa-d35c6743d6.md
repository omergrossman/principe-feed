Siemens Industrial Edge Device Kit Path Traversal Vulnerabilities

Multiple path traversal vulnerabilities in Siemens Industrial Edge Device Kit across versions 1.5–1.28 (both arm64 and x86-64 architectures) could allow authenticated attackers to access sensitive internal information and potentially escalate privileges. Siemens has released patches for recent versions (1.26.2.1, 1.27.1.1, 1.28.0.6) while recommending network segmentation for products without available fixes.
