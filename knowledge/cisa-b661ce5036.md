Siemens SINEC INS Multiple Vulnerabilities Disclosed

Siemens SINEC INS versions prior to V1.0 SP2 Update 6 contain four vulnerabilities including OS command injection, path traversal, privilege escalation via unnecessary capabilities, and weak password hashing with static salt. The vulnerabilities affect critical infrastructure sectors worldwide and require immediate patching to V1.0 SP2 Update 6 or later.
