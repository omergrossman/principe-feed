Schneider Electric EcoStruxure IT Data Center Expert XML Injection Vulnerability

Schneider Electric disclosed a CVE-2026-8045 vulnerability in EcoStruxure IT Data Center Expert versions 9.1.1 and earlier, where authenticated users can submit crafted XML payloads to SOAP endpoints to disclose server-side file contents. The flaw stems from improper restriction of XML external entity references (CWE-611) with a CVSS v3.1 base score of 6.5. Version 9.1.2 contains the remediation and is available for download.
