Bransys ELD Multiple Vulnerabilities in Android and iOS Versions

Three vulnerabilities in Bransys ELD mobile applications affect Android versions below 11.00.00 and iOS versions below 1.1.54. The flaws include hardcoded MQTT and FTP credentials and cleartext transmission of sensitive data, potentially exposing real-time telemetry and device information to unauthorized access. Bransys recommends users update to patched versions via app stores.
