Siemens PSS(R)SINCAL WibuKey Out-of-Bounds Write Vulnerability

Siemens PSS(R)SINCAL contains an out-of-bounds write flaw in the WibuKey third-party licensing driver affecting versions 21.5, 22.0, and 22.5 (prior to update 5). Exploitation could crash affected systems or potentially modify adjacent kernel memory. Patches are available for v22.5.5+; earlier versions require manual installation of WibuKey Runtime 6.72 or later, with vendors recommending network segmentation and validated deployment procedures.
