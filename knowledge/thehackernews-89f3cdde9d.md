Critical NGINX Heap Buffer Overflow Vulnerability Patched

F5 released patches for CVE-2024-6533, a critical heap buffer overflow in NGINX that can be triggered by unauthenticated remote attackers through crafted HTTP requests. The vulnerability affects worker processes and may enable remote code execution or denial of service. Fixes were issued in NGINX 1.30.4, 1.31.3, and NGINX Plus 37.0.3.1 in mid-July.
