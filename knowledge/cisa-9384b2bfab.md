CISA Adds Oracle WebLogic Server Vulnerability to Known Exploited Vulnerabilities Catalog

CISA has added CVE-2024-21182, an Oracle WebLogic Server vulnerability, to its Known Exploited Vulnerabilities Catalog following evidence of active exploitation. Federal agencies are required under BOD 22-01 to remediate the flaw by a specified deadline. CISA recommends all organizations prioritize patching KEV Catalog vulnerabilities as part of standard vulnerability management.
