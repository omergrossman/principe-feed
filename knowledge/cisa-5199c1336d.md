Rockwell Automation Flex 5000 Adapter Denial-of-Service Vulnerability

CISA disclosed a double-free vulnerability (CVE-2026-12659, CVSS 7.5) in Rockwell Automation Flex 5000 Adapter version 6.011 that allows remote attackers to trigger denial-of-service conditions through crafted CIP packets, requiring device power cycling to recover. The vendor has released version 6.012 as a remediation, and CISA recommends standard industrial control system hardening practices including network segmentation and firewall deployment.
