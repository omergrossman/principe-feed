Browser Extension Vulnerability Could Compromise AI Assistants Across Multiple Chromium Browsers

Security researchers demonstrated that a malicious browser extension could gain unauthorized access to AI assistants in five Chromium-based products, including Google's Gemini Live, Microsoft Edge, Perplexity Comet, Opera Neon, and Claude for Chrome. The attack requires only extension installation to enable single-click control over these AI services. The finding highlights a cross-browser vulnerability affecting widely-used AI assistant implementations.
