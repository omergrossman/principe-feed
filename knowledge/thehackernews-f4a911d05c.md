Public PoC Released for Critical libssh2 CVE-2026-55200 Client-Side SSH Flaw

A public proof-of-concept exploit has been released for CVE-2026-55200, a critical vulnerability in libssh2 affecting all versions through 1.11.1. The flaw allows a malicious or compromised SSH server to trigger memory corruption on connecting clients, potentially enabling code execution without requiring credentials or user interaction.
