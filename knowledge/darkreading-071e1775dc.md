Threat Actors Exploit AI Chatbots for Disinformation and Phishing via Web Poisoning

Attackers are deliberately injecting malicious links and fabricated data into web content, then using SEO techniques to ensure these poisoned results appear prominently in AI chatbot responses from systems like ChatGPT, Gemini, and Google AI Overview. This technique leverages the tendency of large language models to draw from indexed web content, creating a scalable vector for phishing and disinformation campaigns.
