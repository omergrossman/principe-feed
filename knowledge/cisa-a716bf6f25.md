Siemens Solid Edge Multiple File Parsing Vulnerabilities

Seven memory safety vulnerabilities affect Siemens Solid Edge SE2025 and SE2026, exploitable through malformed PAR, PSM, or DFT design files. Flaws include out-of-bounds read/write and use-after-free conditions that could enable arbitrary code execution with CVSS 7.8 severity. Siemens has released patched versions (SE2025 v225.0.15 and SE2026 v226.0.7) and recommends immediate updates.
