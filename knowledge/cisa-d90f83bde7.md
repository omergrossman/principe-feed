Critical Authentication and DoS Vulnerabilities in Delta Electronics DVP12SE PLC

CISA disclosed two critical vulnerabilities in Delta Electronics DVP12SE PLCs affecting all firmware versions. CVE-2026-12819 allows unauthenticated remote command execution and modification of control logic via exposed Modbus TCP, while CVE-2026-12818 enables denial-of-service through resource exhaustion. Delta is developing a fix and recommends network isolation, IP filtering, password protection, and VPN use for remote access.
