Compromised jscrambler npm Package Distributes Infostealer via Install Hook

Version 8.14.0 of the jscrambler npm package contained malicious code that executed a Rust-based infostealer during installation through a preinstall hook, with platform-specific binaries for Windows, macOS, and Linux. The compromised release was identified and flagged by security researchers within minutes of publication on July 11, 2026.
