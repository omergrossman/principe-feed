Rockwell Automation 1734 POINT I/O Denial-of-Service Vulnerability

A denial-of-service vulnerability (CVE-2026-10573, CVSS 7.5) affecting Rockwell Automation 1734 POINT I/O version 3.023 allows remote attackers to force the module into a faulted state through crafted CIP messages, requiring a restart to recover. Rockwell recommends migration to version 5034-OB8 or implementation of network segmentation and access controls for affected deployments in critical manufacturing environments.
