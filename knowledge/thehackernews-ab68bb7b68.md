Ahsay Releases Updated Patches for AhsayCBS Authentication and Command Execution Flaws

Ahsay Backup has issued security updates addressing two chained vulnerabilities in AhsayCBS (CVE-2026-105133 and CVE-2026-105134) that bypass authentication and enable arbitrary command execution. These flaws have been actively exploited to deploy web shells and XMRig miners, with previous patches proving incomplete.
