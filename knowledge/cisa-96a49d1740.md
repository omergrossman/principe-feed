Siemens Capital Embedded AR Classic Out-of-Bounds Read Vulnerability

Siemens Capital Embedded AR Classic contains an out-of-bounds read vulnerability (CVE-2026-89208, CVSS 5.3) allowing unauthenticated remote attackers to trigger abnormal behavior or denial of service by sending specially crafted packets. A patch is available for R20-11 versions prior to V2303; the 431-422 line has no fix planned. Siemens recommends network segmentation, firewalls, and isolation of affected devices from internet exposure.
