Siemens License Server Multiple Vulnerabilities

Siemens License Server versions below 5.1 and 5.3 contain two vulnerabilities: a local privilege escalation flaw (CVE-2026-69108, CVSS 6.0) enabling arbitrary command execution as root, and a path traversal issue (CVE-2026-69109, CVSS 7.5) allowing remote file access. Siemens recommends updating to the latest versions and implementing network segmentation for affected systems.
