953 E-commerce Stores Compromised via Magento CMS Blocks in Long-Running Campaign

An unknown threat actor has compromised approximately 953 online stores, predominantly running Magento, since July 2025. The campaign deploys obfuscated JavaScript through CMS blocks to inject malicious loader code into store pages, affecting customers during checkout and payment processes. Sansec identified the activity as part of a sustained operation targeting e-commerce infrastructure.
