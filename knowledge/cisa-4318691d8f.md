Mitsubishi Electric CNC Series Remote Denial-of-Service Vulnerability

CISA has disclosed CVE-2025-2399 affecting multiple Mitsubishi Electric CNC controller models. The vulnerability allows remote attackers to trigger an out-of-bounds read via malformed packets on TCP port 683, causing denial-of-service conditions. Mitsubishi Electric has released patched firmware versions and recommends network isolation, firewall rules, and IP filtering for systems awaiting updates.
