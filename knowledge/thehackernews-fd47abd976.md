Researchers Demonstrate AI-Assisted Exploit Porting Across Industrial Control Systems

Forescout Research used Claude to adapt a pre-authentication RCE exploit originally targeting one WAGO PLC model to work against another, successfully executing arbitrary ARM code on live hardware. The proof-of-concept involved CVE-2021-31886, a stack buffer overflow in Nucleus FTP server's USER command handling, illustrating how AI tooling can accelerate exploit development and adaptation across similar industrial devices.
