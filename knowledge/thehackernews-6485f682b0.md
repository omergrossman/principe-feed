Trojanized Newtonsoft.Json Fork Discovered on NuGet with Game-Rigging Functionality

Researchers identified a typosquatted NuGet package named "Newtonsoftt.Json.Net" that mimics the legitimate Newtonsoft.Json library while containing malicious code designed to manipulate live gaming results on the Digitain platform. The trojanized fork represents a departure from typical supply-chain attacks that focus on credential theft, instead targeting specific gaming infrastructure through a compromised dependency.
