NAVTOR NavBox Hard-coded Credentials Vulnerability (CVE-2026-21404)

NAVTOR NavBox versions up to 4.16.1.20 contain hard-coded credentials in their SOAP/WCF implementation, allowing local attackers with low privileges to extract credentials and access privileged methods for file manipulation. NAVTOR released a patch in April 2026 (version 4.17.2.6+) with automatic updates for active connections. The vulnerability requires local access and high attack complexity; no public exploitation has been reported.
