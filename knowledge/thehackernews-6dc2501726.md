Fake AI Agent Skill Bypassed Security Scanners and Reached 26,000 Deployments

Security firm AIR demonstrated a vulnerability in AI agent skill marketplaces by deploying a benign test skill that circumvented all security scanners it encountered and was installed across approximately 26,000 agents, including those in corporate environments. The proof-of-concept collected user email addresses while evading detection, highlighting gaps in skill validation mechanisms across marketplace platforms.
