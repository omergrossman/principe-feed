N-able Releases Fourth Hotfix in Five Weeks for N-central Unauthenticated RCE Vulnerability

N-able has issued a fourth security patch for its N-central RMM platform in five weeks to address an unauthenticated remote code execution flaw affecting on-premises deployments below version 2026.3.1.14. The vendor's incident notice references wild exploitation, though release notes indicate this status remains unconfirmed. The rapid succession of hotfixes suggests ongoing remediation efforts for critical vulnerabilities in the platform.
