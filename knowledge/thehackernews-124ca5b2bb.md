Attackers Bypass WAFs to Exploit Oracle PeopleSoft Flaw and Deploy Web Shells

Google has identified a widespread exploitation campaign targeting Oracle PeopleSoft systems across multiple sectors, leveraging CVE-2026-35273, a critical vulnerability (CVSS 9.8) that enables unauthenticated remote code execution. The campaign, attributed to ShinyHunters-linked threat actors, demonstrates capability to bypass web application firewalls and establish persistent access through web shell deployment.
