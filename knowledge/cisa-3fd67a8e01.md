AzeoTech DAQFactory Type Confusion Vulnerability (CVE-2026-12390)

A type confusion vulnerability in AzeoTech DAQFactory versions 21.1 and earlier allows local attackers to achieve arbitrary code execution through specially crafted .ctl files, with CVSS scores of 7.8 (v3.1) and 8.4 (v4.0). CISA recommends restricting .ctl file access to admin-only directories, using Safe Mode when loading untrusted documents, and applying document editing passwords. No public exploitation has been reported.
