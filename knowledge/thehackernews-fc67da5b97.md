WordPress Comment2Shell Vulnerability Enables RCE Through Admin Session Hijacking

A vulnerability in WordPress core (CVE-2026-93485) allows unauthenticated users to inject malicious scripts via comments, which execute with administrator privileges when site admins view the affected page, potentially leading to remote code execution. WordPress addressed the flaw in version 7.1.1 released on September 17, with vendor guidance recommending immediate patching across affected installations.
