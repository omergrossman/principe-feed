CrashStealer macOS Malware Uses Notarized Dropper to Evade Gatekeeper

Researchers identified CrashStealer, a macOS information stealer written in native C++ that uses Apple-notarized droppers to bypass Gatekeeper security checks. The malware validates victim credentials locally before exfiltrating sensitive data, distinguishing it from prior macOS stealers built on AppleScript or Objective-C frameworks.
