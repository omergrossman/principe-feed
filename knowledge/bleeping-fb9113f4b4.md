BragJack Attack Demonstrates AI Browser Agent Hijacking via Malicious Extensions

Security researcher Gal Weizman from Forever Security disclosed BragJack, a proof-of-concept attack that compromises AI assistants across multiple browsers and platforms through a single malicious extension. The attack leverages prompt forcing techniques and has resulted in $20,000 in bug bounties and two CVE assignments, highlighting a vulnerability class affecting Chrome, Edge, Opera Neon, Perplexity Comet, and Claude integrations.
