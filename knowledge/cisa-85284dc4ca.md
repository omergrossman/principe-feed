OPC UA LocalDiscoveryServer Privilege Escalation Vulnerability

OPCFoundation released a security advisory addressing CVE-2026-77477 in OPC UA LocalDiscoveryServer (LDS) versions prior to 1.04.420. An attacker with local access during installation can intercept elevated-privilege console windows to execute arbitrary commands. The vulnerability requires attacker proximity and administrator-level installer execution; no remote exploitation has been documented.
