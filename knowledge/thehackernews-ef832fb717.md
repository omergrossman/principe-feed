CornFlake RAT Delivered via Compromised Hotel Wi-Fi Networks

Microsoft researchers identified an operation dubbed CaptiveCrunch that exploits compromised hotel Wi-Fi networks to distribute fake browser updates containing CornFlake, a remote access trojan capable of capturing webcam feeds, audio, and keyboard input. The activity is attributed to Storm-2945, assessed as a subcluster of the Midnight Blizzard threat actor. The attack vector leverages the trust users place in software updates on public networks.
