CISA Advisory: Eufy Omni C20 and X10 Pro Remote Code Execution Vulnerabilities

CISA published a security advisory for Eufy Omni C20 and X10 Pro security cameras affecting versions prior to 1.6.4. Three vulnerabilities—including unauthenticated command injection (CVSS 9.4), hard-coded credentials, and improper certificate validation—could allow attackers to execute arbitrary code or conduct man-in-the-middle attacks. Eufy recommends immediate patching to version 1.6.4 or later; CISA advises network segmentation and restricting internet exposure for these devices.
