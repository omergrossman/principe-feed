OFFIS DCMTK Toolkit Multiple Critical Vulnerabilities

CISA disclosed five vulnerabilities affecting OFFIS DCMTK Toolkit versions 3.7.0 and earlier, with CVSS scores ranging from 7.5 to 9.8. Flaws include path traversal enabling unauthorized file writes, memory exhaustion via repeated requests, unauthorized data access across logical boundaries, and denial-of-service conditions. Vendor has released fixes available on GitHub; users should update to the latest release.
