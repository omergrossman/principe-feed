CISA Adds Ray Project Code Injection Vulnerability to Known Exploited Vulnerabilities Catalog

CISA has cataloged CVE-2025-62593, a code injection flaw in Ray Project, as an actively exploited vulnerability. The addition reinforces BOD 26-04 requirements for federal agencies to prioritize patching of KEV-listed vulnerabilities on internet-facing systems. CISA encourages all organizations to adopt similar risk-based vulnerability management practices.
