Langflow Critical RCE Vulnerability Actively Exploited in Honeypot Campaign

Threat actors are conducting exploitation attempts against CVE-2026-105740, a critical authenticated remote code execution flaw in Langflow, an open-source AI application development platform. Previdian telemetry detected 1,423 honeypot exploit attempts targeting the vulnerability, which carries a CVSS score of 9.9. The platform, now under IBM ownership following DataStax's acquisition in February 2025, requires immediate patching attention.
