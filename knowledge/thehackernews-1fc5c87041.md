Amazon Q Developer Vulnerability Allowed Credential Theft via Malicious Repositories

A high-severity flaw in Amazon Q Developer (CVE-2026-12957, CVSS 8.5) enabled malicious repositories to execute arbitrary commands and exfiltrate cloud credentials when opened by developers. The vulnerability stemmed from improper validation of Model Context Protocol server configurations, requiring only that a user trust the workspace to trigger exploitation. Amazon has released a patch addressing the issue.
