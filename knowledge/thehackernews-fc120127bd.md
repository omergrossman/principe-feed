SAP Addresses Critical Memory Corruption Vulnerability in NetWeaver ABAP

SAP released security updates in July 2026 to remediate multiple vulnerabilities, including CVE-2026-44747 (CVSS 9.9) affecting NetWeaver Application Server ABAP. The flaw is an out-of-bounds write issue stemming from memory management logic errors that authenticated attackers could exploit to corrupt memory and potentially access or modify sensitive data.
