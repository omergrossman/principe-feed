Exposed LLM Inference Honeypot Reveals Supply-Chain Attack Vector

A researcher's internet-exposed LLM inference honeypot was discovered, rebranded with legitimate model identities, and integrated into a "free" LLM backend service. The honeypot received coding-agent session data including execution history, filesystem details, and tool manifests—demonstrating how adversaries positioned within LLM supply chains could intercept sensitive operational context from downstream users.
