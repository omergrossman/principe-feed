ABB Ability Edgenius Linux Kernel Privilege Escalation Vulnerability

ABB has released a security update addressing CVE-2026-31431, a Linux kernel vulnerability in Ability Edgenius versions 3.2.0.0 through 3.2.4.0 that permits local authenticated users to escalate privileges to root. The flaw resides in the algif_aead cryptographic interface and requires local system access to exploit. Version 3.2.4.1 resolves the issue.
