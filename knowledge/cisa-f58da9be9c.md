Red Lion Controls N-Tron 700 Series Multiple Vulnerabilities

CISA disclosed seven vulnerabilities in Red Lion Controls N-Tron 700 Series network switches affecting firmware versions ≤3.11.0 and bootloader ≤2.0.6.1. Flaws include hardcoded credentials, plaintext credential storage, weak encryption, and missing authentication controls that allow administrative access and device manipulation. Red Lion recommends upgrading to firmware 3.11.1 or later and implementing mitigations including SNMP configuration restrictions and web GUI access controls.
