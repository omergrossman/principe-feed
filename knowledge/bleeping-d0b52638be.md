Hackers exploit Collabora RCE flaw to backdoor Nextcloud servers

Threat actors are actively exploiting CVE-2026-110447, a critical remote code execution vulnerability in the Collabora Online - Built-in CODE Server app for Nextcloud, to establish persistent access on affected servers. The vulnerability allows unauthenticated command execution, enabling attackers to deploy backdoors and maintain long-term presence within compromised Nextcloud instances.
