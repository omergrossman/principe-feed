ST Engineering iDirect iQ-Series Satellite Terminals: Authentication and CSRF Vulnerabilities

CISA disclosed two vulnerabilities in ST Engineering iDirect iQ-Series satellite terminals (Evolution, 3315, and 9-Series models through version 4.5.2.1). CVE-2026-38059 allows unauthenticated attackers to retrieve sensitive device credentials and authentication material via exposed REST API endpoints, while CVE-2026-38057 enables cross-site request forgery attacks to trigger denial-of-service conditions on authenticated administrative sessions. Patches are available in version 4.5.2.2; mitigation includes network segmentation, API access controls, and monitoring for anomalous activity.
