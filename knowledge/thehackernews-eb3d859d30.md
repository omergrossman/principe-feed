Windmill Open-Source Platform Exploited via Unauthenticated Path Traversal Vulnerability

A high-severity path traversal flaw (CVE-2026-29059, CVSS 7.5) in the open-source Windmill developer platform is being actively exploited in the wild. The vulnerability allows unauthenticated attackers to read arbitrary server files through improper input validation in the get_log_file API endpoint.
