Attacker Hijacks AI Coding Assistant to Deploy Shai-Hulud Worm Across Enterprise Repositories

Mandiant documented an incident where an attacker compromised an active AI coding-assistant session at a SaaS provider, leveraging the assistant to recommend poisoned software that propagated a worm called Shai-Hulud to approximately 100 internal repositories. The worm subsequently exfiltrated repository credentials and source code from the affected environment.
