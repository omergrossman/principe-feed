ABB Ability Zenon IIoT Services Vulnerabilities in Bundled MongoDB

CISA published advisories for multiple vulnerabilities affecting ABB Ability Zenon deployments with bundled MongoDB (4.2), including heap memory disclosure and arbitrary memory access issues with CVSS scores ranging from 6.5 to 8.7. The flaws stem from improper handling of protocol parameters and serialization in MongoDB versions prior to specified patches. ABB recommends either upgrading to patched MongoDB versions or uninstalling IIoT services if not operationally required.
