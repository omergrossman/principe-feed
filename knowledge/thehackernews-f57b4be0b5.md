Critical Atlassian Flaw Enables Unauthenticated File Access Across 8 Data Center Products

A critical vulnerability (CVE-2026-21589, CVSS 9.3) in eight Atlassian Data Center products allows unauthenticated attackers to read files from the web application root directory if the exact file path is known. The flaw requires no login credentials and affects self-hosted deployments, though attackers cannot enumerate directory contents.
