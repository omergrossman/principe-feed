Critical Unauthenticated RCE in Orkes Conductor Workflow Platform Under Active Exploitation

A critical pre-authentication remote code execution vulnerability (CVE-2026-58138, CVSS 9.8) affecting Orkes Conductor versions before 3.30.2 is being actively exploited in the wild. The flaw permits unauthenticated attackers to execute arbitrary code on affected systems. Organizations running vulnerable versions should prioritize patching to version 3.30.2 or later.
