CISA Advisory: Multiple High-Severity Vulnerabilities in NextGen Healthcare Mirth Connect

CISA disclosed three high-severity vulnerabilities in NextGen Healthcare Mirth Connect versions 4.7.1 and earlier, including SQL injection and XML external entity (XXE) flaws that could enable credential disclosure, arbitrary file operations, and denial-of-service attacks. Mirth Connect is widely deployed across healthcare infrastructure globally. NextGen Healthcare has released version 4.7.2 as a remediation; organizations are advised to update and apply network segmentation controls.
