Prompt Injection Vulnerability in Amazon Kiro IDE Enables Data Exfiltration

Researchers identified a prompt injection vulnerability in Amazon Kiro, an AI-powered agentic IDE, that could allow attackers to exfiltrate sensitive data through Kiro Powers. The flaw affects Kiro IDE version 0.7.45 on Windows and lacks a CVE assignment. The vulnerability demonstrates risks associated with agent-based AI tooling when exposed to untrusted inputs.
