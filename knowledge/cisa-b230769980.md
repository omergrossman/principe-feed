Rockwell Automation FactoryTalk Historian Site Edition Vulnerabilities

CISA disclosed three vulnerabilities in Rockwell Automation FactoryTalk Historian Site Edition affecting version 11 and earlier. These issues enable authentication bypass through repeated login requests, denial-of-service conditions via uncaught exceptions, and potential data loss in snapshot caches. Rockwell Automation provides patches and recommends network segmentation, service monitoring, and access controls for affected deployments.
