Siemens Parasolid Out-of-Bounds Read Vulnerability

Siemens Parasolid versions V38.0 and V38.1 contain an out-of-bounds read vulnerability (CVE-2026-64629, CVSS 7.8) triggered when processing specially crafted X_T format files, potentially enabling arbitrary code execution. Siemens has released patches (V38.0.235 and V38.1.230) and recommends immediate updates. The vulnerability affects critical manufacturing infrastructure globally.
