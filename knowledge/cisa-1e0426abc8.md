Siemens Siveillance Control Arbitrary File Upload Vulnerability

A critical vulnerability in the Open Interface Services web module of Siemens Siveillance Control and Control Pro (versions 3.x and 4.x) permits authenticated attackers to upload arbitrary files, potentially achieving root-level code execution on affected servers. Siemens has released patched versions for all affected product lines; organizations should update to the specified patched versions and implement network segmentation controls.
