Cross-Site Scripting Vulnerability in OpenPLC Runtime v3

CISA disclosed a reflected XSS vulnerability (CVE-2026-88020, CVSS 6.1) in OpenPLC Runtime v3 affecting critical infrastructure sectors globally. An attacker could hijack operator sessions and manipulate programmable logic controllers. Autonomy Logic recommends upgrading to OpenPLC v4, as v3 is end-of-life and no longer patched.
