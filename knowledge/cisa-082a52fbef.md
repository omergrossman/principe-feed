Siemens SIMATIC S7 Webserver API .NET Client Library Vulnerabilities

Two vulnerabilities in Siemens .NET Client Library for SIMATIC S7 Webserver API (CVE-2026-85114, CVE-2026-85115) permit path traversal attacks enabling arbitrary file writes and exposure of plaintext restore passwords through error messages. Siemens has issued patched versions 3.3.61 and 3.3.62 and recommends immediate updating. The vulnerabilities affect critical infrastructure sectors globally, including manufacturing, energy, transportation, and healthcare.
