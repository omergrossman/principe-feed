Out-of-Bounds Read Vulnerability in MZ Automation lib60870

CISA disclosed a high-severity out-of-bounds read vulnerability (CVE-2026-16002) in MZ Automation lib60870 versions up to 2.4.0 that could allow remote attackers to crash the parsing process and cause denial of service. The library is deployed across critical infrastructure sectors globally. MZ Automation recommends immediate patching to version 2.4.1 or later.
