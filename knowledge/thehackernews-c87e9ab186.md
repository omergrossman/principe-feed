Microsoft 365 Copilot Enterprise Search Vulnerability Enabled Single-Click Data Exfiltration

Researchers at Varonis Threat Labs identified a vulnerability chain in Microsoft 365 Copilot Enterprise Search that could allow attackers to exfiltrate emails, calendar data, and files through a single malicious link spoofing a legitimate Microsoft domain. The attack bypassed traditional URL filtering because it leveraged authentic Microsoft infrastructure, though the specific technical details and remediation status were not fully disclosed in the initial announcement.
