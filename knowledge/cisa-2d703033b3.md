Johnson Controls Metasys XSS Vulnerability Affecting Multiple Versions

CISA disclosed a persistent cross-site scripting vulnerability (CVE-2026-34491) in Johnson Controls Metasys versions 12–15 that allows low-privilege users to inject malicious payloads via crafted URLs, potentially enabling session hijacking and administrative access. Patches are available for Metasys 15.0.1 and 14.1.5; versions 12 and 13 have reached end-of-support and require migration to newer releases. CISA recommends network isolation, access controls, and WAF deployment to reduce exploitation risk.
