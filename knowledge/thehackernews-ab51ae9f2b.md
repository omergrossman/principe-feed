ThreatsDay: Multiple Attack Vectors Identified Including AI Zero-Day Chain and Exposed Credentials

Security researchers documented multiple attack pathways exploiting unexpected system behaviors across model inspection, caching mechanisms, and credential storage. The findings included an AI-powered zero-day chain, over 543,000 exposed secrets in active use, and remote code execution via model inspection. The analysis emphasizes how attackers leverage ordinary system functions—inspection, caching, compilation, and storage—when implementations exceed expected scope.
