Rockwell Automation ThinManager Path Traversal Vulnerability

CISA has disclosed a path traversal vulnerability in Rockwell Automation ThinManager affecting versions 13.0.0 through 14.0.2, allowing authenticated attackers to write arbitrary files to restricted directories. The vulnerability carries a CVSS 3.1 score of 8.1 (HIGH). Rockwell Automation has released patched versions (13.1.6, 13.2.5, 14.0.3) and recommends standard ICS security practices including network isolation and VPN deployment for organizations unable to upgrade immediately.
