Brotli Decoder Vulnerability Affects Multiple Software Projects Including Node.js, Bun, and Python

A memory-corruption vulnerability in Google's Brotli decoder affects numerous widely-used libraries and applications including Node.js, Bun, Python Brotli packages, and Envoy proxies. Tracked as CVE-2026-111497, the flaw enables crafted compressed data to trigger buffer overflow conditions that corrupt program memory and potentially lead to code execution.
