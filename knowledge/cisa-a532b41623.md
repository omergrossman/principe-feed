Rockwell Automation RSLinx Classic Stack-Based Buffer Overflow Vulnerability

CISA disclosed a stack-based buffer overflow vulnerability (CVE-2020-13573) in Rockwell Automation RSLinx Classic versions 4.50.00 and earlier, affecting critical manufacturing and energy sectors globally. The flaw allows remote code execution with a CVSS v3.1 score of 7.5. Rockwell recommends upgrading to version 4.60.00 or later, or applying patch BF31213 for systems unable to upgrade immediately.
