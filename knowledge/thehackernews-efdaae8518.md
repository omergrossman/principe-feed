Langflow CVE-2026-5027 Unauthenticated RCE Exploited in Active Campaigns

An unpatched high-severity path traversal vulnerability (CVE-2026-5027, CVSS 8.8) in Langflow, an open-source low-code AI application platform, is being actively exploited to achieve unauthenticated remote code execution. The flaw permits attackers to write files to arbitrary system locations, as documented by VulnCheck.
