CISA Malcolm Network Traffic Analysis Tool Affected by Multiple Vulnerabilities

CISA has disclosed five vulnerabilities in Malcolm, a network traffic analysis tool suite, affecting versions prior to 26.07.0 (with one requiring 26.06.1). The issues include uncontrolled resource allocation in archive extraction, path traversal in directory creation, unrestricted dangerous file uploads, and authorization bypass via path normalization mismatches. Successful exploitation could enable denial-of-service conditions or arbitrary code execution with container-level privileges.
