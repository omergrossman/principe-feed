Weekly Security Recap: Multiple Vulnerabilities Across Chrome, UniFi, macOS, and VPN Systems

A collection of security incidents emerged this week involving a Chrome zero-day, UniFi exploits, macOS malware variants, and VPN vulnerabilities. Common themes included exposure of legacy infrastructure, abandoned dependencies being weaponized, and deprecated features remaining active in production environments. The recap highlights recurring risk patterns around legacy systems, phishing infrastructure accessibility, and inadequate lifecycle management of software components.
