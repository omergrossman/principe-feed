Varonis Discloses Data Exfiltration Vulnerabilities in Microsoft Copilot Personal

Varonis Threat Labs identified three vulnerabilities in Microsoft Copilot Personal that could enable unauthorized data extraction from connected applications through a single malicious link click. The attack chain, termed CoSnitch, exploits an undocumented URL parameter exposed by the assistant itself to exfiltrate information accessible within a user's Copilot session.
