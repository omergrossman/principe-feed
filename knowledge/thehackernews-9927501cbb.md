Four Espionage Groups Deployed BlueMoon Exploit Kit Targeting Windows and Chrome

A previously undocumented exploit kit named BlueMoon, which chains multiple vulnerabilities in Microsoft Windows and Google Chrome, has been observed in active use by at least four state-sponsored threat groups. Initial in-the-wild deployment was attributed to APT31, a China-aligned actor, with subsequent adoption by other espionage-focused threat clusters within a narrow timeframe.
