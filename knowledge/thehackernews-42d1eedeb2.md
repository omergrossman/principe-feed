Compromised npm Packages in @joyfill Namespace Deliver Remote Access Trojan

Two beta-release npm packages within the @joyfill namespace were found to contain malicious code that executes a remote access trojan upon import. The affected versions (@joyfill/layouts@0.1.2-2773.beta.0 and @joyfill/components@4.0.0-rc24-2773-beta.4) include an import-time implant associated with the DEV#POPPER malware family. Developers using these specific versions should audit their dependencies and update to patched releases.
