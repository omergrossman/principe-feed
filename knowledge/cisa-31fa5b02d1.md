Rockwell Automation Logix Platform Denial-of-Service Vulnerability

CISA disclosed a buffer validation flaw (CVE-2026-9637) affecting multiple Rockwell Automation Logix controller platforms across multiple firmware versions. The vulnerability allows unauthenticated remote attackers to trigger a denial-of-service condition via malformed CIP messages, requiring manual power cycling to restore operation. Rockwell has released patched firmware versions (V37.011, 34.015, 35.014, 36.013) and recommends immediate updating or network isolation as mitigation.
