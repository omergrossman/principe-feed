Eclipse Foundation Eclipse Milo Vulnerabilities Allow Data Deletion, Credential Recovery, and Denial of Service

Multiple vulnerabilities in Eclipse Milo versions up to 1.1.4 could enable attackers to delete protected data, recover user credentials, impersonate users, or disrupt server availability. The Eclipse Foundation recommends upgrading to version 1.1.5; users on the legacy 0.6.x branch must migrate to 1.1.5 or later as no patched 0.6.x releases are available. CVSS scores range from 5.3 to 6.9 (medium severity).
