Microsoft Patches 398 Flaws Including Active Windows Driver Zero-Day

Microsoft released 398 security updates this month, including a privilege escalation vulnerability in a core Windows kernel driver handling network socket operations that is currently being exploited in the wild. The flaw (CVE-2026-68820, CVSS 7.0) allows attackers with local code execution to escalate privileges to SYSTEM level and was prioritized for immediate patching.
