China-Linked UNC3569 Exploited Sogou Input Method Vulnerability to Deploy GRAYRABBIT Backdoor

UNC3569, a China-linked threat actor, leveraged a vulnerability in Sogou Input Method—widely deployed on Windows systems in China—to achieve code execution and install the GRAYRABBIT backdoor. The attack chain began with a malicious link and culminated in post-compromise capabilities matching the privileges of the logged-in user. Tencent, the input method's owner, was identified in the campaign.
