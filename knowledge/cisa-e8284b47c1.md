Hitachi Energy ITT600 Explorer Vulnerabilities (CVE-2024-8176, CVE-2025-59375)

Hitachi Energy disclosed two stack overflow and resource allocation vulnerabilities in ITT600 Explorer versions prior to 2.1 SP6, affecting the libexpat library used for IEC61850 simulation functionality. Both vulnerabilities carry a CVSS 3.1 base score of 7.5 and can enable denial-of-service attacks; exploitation requires local access or network connectivity to affected IEC61850 server simulation features. Remediation includes updating to version 2.1 SP6 HF1 or awaiting version 2.2.
