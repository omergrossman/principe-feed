Yokogawa FAST/TOOLS and CI Server Cleartext Transmission Vulnerability

CISA has published a vulnerability affecting Yokogawa FAST/TOOLS and Collaborative Information Server that allows unauthenticated network-based attackers to retrieve CI Server configuration data via cleartext transmission (CVE details referenced in YSAR-26-0004). The vulnerability carries a CVSS 3.1 base score of 7.5 (HIGH). Yokogawa recommends updating FAST/TOOLS to R10.04 SP4 and CI Server to R1.05, with additional mitigation involving network segmentation and access controls.
