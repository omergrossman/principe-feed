Orthanc DICOM Server Heap Buffer Overflow Vulnerability (CVE-2026-87020)

CISA disclosed a high-severity integer overflow vulnerability in Orthanc DICOM Server versions prior to 1.13.0 that allows authenticated remote attackers to trigger heap out-of-bounds writes when processing malicious PNG or JPEG images, potentially causing process crashes and denial-of-service conditions. The vendor recommends immediate updates to version 1.13.0. No active exploitation has been reported.
