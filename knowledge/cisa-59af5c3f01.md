Rockwell Automation FLEX I/O EtherNet/IP Adapters Vulnerabilities

CISA disclosed two vulnerabilities in Rockwell Automation FLEX I/O EtherNet/IP Adapters (models 1794-AENTR and 1794-AENTRXT V2.012): a denial-of-service issue from improper memory handling of CIP protocol requests, and an authentication bypass allowing unauthenticated modification of device passwords. Rockwell Automation released firmware version 2.013 to address both issues, with CVSS scores reaching 9.4 for the authentication vulnerability.
