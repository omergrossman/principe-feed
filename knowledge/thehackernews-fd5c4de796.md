LiteLLM Gateways Widely Exposed with Default Example Admin Keys

Wiz Research identified that approximately 10% of internet-facing LiteLLM gateways scanned in February accepted the example administrative key 'sk-1234' from the project's setup documentation. This default credential, intended only for demonstration purposes, provides full gateway access including the ability to read all API traffic and model provider interactions. The exposure affects deployments of LiteLLM, an open-source AI gateway used to broker requests between applications and external language model providers.
