TerminalFix ClickFix Variant Targets Windows Terminal with Fake Cloudflare CAPTCHAs

Microsoft identified TerminalFix, a new variant of ClickFix malware that uses fraudulent Cloudflare CAPTCHA pages to deceive users into executing malicious commands via Windows Terminal or PowerShell. The attack aims to install a reverse-tunnel backdoor by exploiting user trust in legitimate security verification prompts.
