Critical RCE Vulnerability in Ruflo MCP Framework Exposes AI Agent Systems

Researchers identified a maximum-severity flaw (CVE-2026-59726, CVSS 10.0) in Ruflo, an open-source model control protocol framework for Anthropic Claude and OpenAI integrations, allowing unauthenticated remote code execution across all versions prior to 3.16.3. The vulnerability, named RufRoot, enables attackers to execute arbitrary commands and manipulate AI memory through the agent meta-harness architecture.
