Attackers Exploit Critical Switchvox Vulnerability for Unauthenticated Remote Code Execution

A critical SQL injection vulnerability (CVE-2026-9586, CVSS 9.3) in Sangoma Switchvox SMB Edition 8.3 allows unauthenticated threat actors to execute arbitrary code remotely. Exploitation has been observed in the wild with attackers deploying reverse shells to compromised systems.
