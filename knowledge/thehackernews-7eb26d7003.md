Over 440,000 Exploit Attempts Target Super Forms and Elementor Pro RCE Flaws

Threat actors are actively exploiting critical remote code execution vulnerabilities in the WordPress plugins Super Forms and Elementor Pro, with over 440,000 attack attempts documented by Wordfence. The flaws enable unauthenticated file uploads and code execution, affecting a significant portion of WordPress deployments relying on these widely-used page builders.
