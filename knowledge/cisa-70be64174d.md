CISA Advisory: Critical Buffer Overflow in Savannah lwIP SMTP Client 2.2.1

A critical buffer overflow vulnerability (CVE-2026-15340, CVSS 9.8) has been identified in Savannah lwIP SMTP client 2.2.1, affecting devices deployed worldwide in energy and water infrastructure. The flaw allows unauthenticated remote code execution or device crash due to insufficient input validation. A patch has been released and is available via git commit.
