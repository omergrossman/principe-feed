Adform Ad Script Compromised to Redirect Cryptocurrency Transactions

Attackers compromised a JavaScript file served by ad tech provider Adform to inject code that intercepted and replaced cryptocurrency wallet addresses in browser sessions. The attack affected sites using Adform's scripts on July 27, 2026, before the company detected the intrusion, removed the malicious payload, and notified customers. Users who copied cryptocurrency addresses while visiting affected pages during the incident window may have received attacker-controlled wallet identifiers.
