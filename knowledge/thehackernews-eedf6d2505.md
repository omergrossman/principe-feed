CISA Adds Actively Exploited Joomla JCE Vulnerability to KEV Catalog

CISA has catalogued a critical access control flaw (CVE-2026-48907, CVSS 10.0) in the Joomla Content Editor plugin as actively exploited in the wild. The vulnerability enables arbitrary code execution through improper authorization controls. Organizations using the affected JCE component should prioritize patching.
