Haiwell IoT Cloud HMI Gateway OS Command Injection Vulnerability

CISA disclosed a critical OS command injection vulnerability (CVE-2026-19188) in Haiwell IoT Cloud HMI Gateway version 3.40.1.12, affecting the Net Check feature's cmdPing Socket.io event. An unauthenticated attacker could execute arbitrary OS commands with root privileges via improper input sanitization. Haiwell released patch version 3.50.1.19 to address the issue; no active exploitation has been reported.
