Inductive Automation Ignition Privilege Escalation Vulnerability

A privilege escalation vulnerability in Inductive Automation Ignition software (versions 8.1.0–8.3.8) allows authenticated low-level users to elevate their access rights, rated HIGH severity (CVSS 8.8). Inductive Automation released patched versions 8.3.9 and 8.1.55 in August and September 2025; users should update immediately. No active exploitation has been reported.
