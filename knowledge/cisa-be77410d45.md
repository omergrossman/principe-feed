B&R PPT30 Operating System OPC-UA Server Denial of Service Vulnerability

A resource exhaustion vulnerability (CVE-2025-11482, CVSS 7.5) in B&R PPT30 Operating System versions prior to 1.8.0 allows unauthenticated network-based attackers to render the OPC-UA server inaccessible. The vulnerability requires network access and affects industrial automation systems deployed across critical infrastructure sectors globally. B&R has released version 1.8.0 as a fix; mitigation includes disabling the OPC-UA server by default and restricting network access via firewalls.
