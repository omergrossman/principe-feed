Zero Trust for AI Agents: Security Framework for Autonomous AI Deployment

Anthropic's framework addresses security architecture for deploying autonomous AI agents in enterprise environments, extending Zero Trust principles beyond traditional infrastructure. The guide identifies six primary threat vectors: prompt injection (direct and indirect), tool misuse including MCP poisoning and tool-chaining attacks, identity and privilege abuse through unscoped delegation and memory-based privilege retention, memory and context poisoning via RAG corruption, supply chain risks spanning model weights and dependencies (demonstrating 250 malicious documents can backdoor LLMs at 600M–13B parameters), and resource exhaustion attacks exploiting automation. The framework operationalizes Zero Trust's three core tenets—never trust/always verify, assume breach, least privilege—with agent-specific extensions including "least agency" (restricting tool capabilities, frequency, and scope) and blast radius containment. Implementation guidance addresses regulated sectors (healthcare, finance, government) requiring agent action verification and minimum necessary permissions, aligned with emerging government mandates including U.S. federal Zero Trust adoption by 2027, UK NCSC and Australian guidance, and NIST SP 800-207 standards.
