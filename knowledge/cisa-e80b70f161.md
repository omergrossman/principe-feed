Siemens Industrial Edge App Publisher Vulnerabilities Allow Remote Code Execution

Siemens Industrial Edge App Publisher versions prior to 1.27.9 contain two chained vulnerabilities: improper TLS certificate validation enabling man-in-the-middle attacks, and insufficient input sanitization in Node.js-integrated components permitting arbitrary code execution. Siemens has released version 1.27.9 as a remediation for affected deployments across critical infrastructure sectors globally.
