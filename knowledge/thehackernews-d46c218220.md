Multiple Vulnerabilities Discovered in Widely-Deployed FatFs Filesystem Library

Security researchers at runZero identified seven vulnerabilities in FatFs, a lightweight filesystem library embedded in firmware across millions of devices including security cameras, drones, industrial controllers, and hardware wallets. The flaws affect a foundational component used to handle FAT and exFAT format operations on removable storage media. The widespread integration of FatFs into embedded device firmware creates potential exposure across multiple device categories.
