Abandoned Popcorn Time App Vulnerability Allowed Remote Code Execution

Researchers identified a critical vulnerability in the Time4Popcorn application, a fork of the Popcorn Time BitTorrent client, that could enable remote code execution with elevated privileges across millions of devices. The vulnerability existed within the app's updater mechanism. Researchers took defensive action by remotely disabling the vulnerable updater to mitigate exposure while the application remains unmaintained.
