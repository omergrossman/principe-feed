Cisco Unified CM Vulnerability Under Active Exploitation Following PoC Release

A critical flaw in Cisco Unified Communications Manager and Unified CM Session Management Edition (CVE-2026-20230, CVSS 8.6) is being actively exploited in the wild following public disclosure of proof-of-concept code. The vulnerability stems from improper input validation in HTTP request handling, permitting unauthenticated remote attackers to achieve file-write capabilities and potential privilege escalation to root.
