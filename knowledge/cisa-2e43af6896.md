Siemens WTV676 and WTV776 Denial of Service Vulnerability

Siemens WTV676 and WTV776 devices contain an input validation flaw (CVE-2026-89207) that allows unauthenticated remote attackers to trigger protection mode, disabling web-based remote access. CVSS score is 6.5 (medium). Siemens has released patched versions (3.94 for WTV676, 4.17 for WTV776) and recommends immediate updates alongside network segmentation controls.
