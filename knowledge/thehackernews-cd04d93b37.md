Weekly Recap: Proxy Botnets, Browser Ransomware, AI Agent Tricks, Fake PoC Malware

The week's threat landscape highlighted compromises across mundane infrastructure and software components: consumer streaming devices repurposed as proxy botnets, browser-based ransomware, AI systems susceptible to prompt injection, and malicious proof-of-concept code. Common vulnerability patterns centered on excessive trust assumptions in ordinary systems—from device firmware to code repositories to permission flows—rather than sophisticated novel attacks.
