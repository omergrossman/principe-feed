LiteLLM Vulnerability Chain Enables Privilege Escalation and Server Takeover

Researchers at Obsidian Security disclosed a vulnerability chain in LiteLLM, a widely deployed open-source AI gateway, that allows low-privilege default accounts to escalate to full administrative access and execute arbitrary code on affected servers. The exploit exposes all provider API keys stored on the compromised gateway, affecting the 100+ language model providers LiteLLM brokers requests to.
