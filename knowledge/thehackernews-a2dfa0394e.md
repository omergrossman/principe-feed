PEERSTITCH Malware Deployed via FortiOS Path Traversal Vulnerability

A threat actor has exploited CVE-2025-61624, a path traversal flaw in Fortinet FortiOS and related products, to deliver PEERSTITCH, a previously unknown ARM64 memory-resident malware. The vulnerability (CVSS 5.4) affects the command line interpreter across multiple Fortinet platforms and enables bypass of security checks on tagged VPN sessions.
