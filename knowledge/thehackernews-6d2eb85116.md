Two Root RCE Vulnerabilities Disclosed in Unitree G1 EDU Humanoid Robot

Security researcher Olivier Laflamme disclosed two independent root remote code execution chains in the Unitree G1 EDU humanoid robot. One vulnerability exploits a network-adjacent path through chat_go and bashrunner components, while the other operates over Bluetooth Low Energy to reach the Locomotion PC with root privileges. Both flaws have been assigned CVE identifiers (CVE-2026-76639 and CVE-2026-76640).
