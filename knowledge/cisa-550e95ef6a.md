Hitachi Energy TRO600 Series Multiple Vulnerabilities Enable Remote Code Execution and File Disclosure

Hitachi Energy disclosed two vulnerabilities affecting TRO600 series products (versions 9.2.1.6 and prior for CVE-2026-10756; 9.1.1.0 and prior for CVE-2026-106087). CVE-2026-10756 allows authenticated attackers to bypass network restrictions via port forwarding, while CVE-2026-106087 permits unauthenticated arbitrary file read access. Both vulnerabilities carry CVSS 7.5-8.7 severity; remediation involves updating to versions 9.2.2.1 or 9.1.2.0.
