Siemens Reyrolle 7SR5 Multiple Vulnerabilities Below V2.70

Siemens Reyrolle 7SR5 protection relay devices prior to version 2.70 contain 14 vulnerabilities, including critical authentication bypass and session prediction flaws. The issues span integer overflows, memory corruption, and insufficient entropy in the embedded web server. Siemens has released version 2.70 as remediation.
