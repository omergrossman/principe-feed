Apple CoreGraphics PoC Published for CVE-2026-86950; PDF-Based Delivery Suspected

A public proof-of-concept has been released for CVE-2026-86950, a memory corruption vulnerability in Apple CoreGraphics that Apple attributes to targeted attacks. The flaw is triggered via malicious PDFs with specially crafted embedded fonts, causing system crashes on unaffected iPhones and Macs. WhatsApp's PDF security checks suggest this may represent a potential delivery mechanism for exploitation.
