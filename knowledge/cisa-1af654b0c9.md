HMS Networks PEAK-System PCAN Windows Driver Vulnerabilities

CISA published a vulnerability advisory covering six flaws in HMS Networks PEAK-System PCAN Windows drivers (versions ≤5.1.2.1151 for setup, ≤5.1.2 for device drivers) affecting critical infrastructure sectors globally. The vulnerabilities stem from improper input validation and buffer handling, potentially permitting local privilege escalation and kernel crashes; HMS Networks has released patched version 5.1.4.
