JADEPUFFER: Agentic ransomware for automated database extortion

Sysdig Threat Research Team documented what it assesses to be the first agentic ransomware campaign, where an LLM-driven threat actor (JADEPUFFER) conducted a fully automated end-to-end extortion operation. Initial access was gained through CVE-2025-3248, an unauthenticated remote code execution flaw in Langflow (an open-source LLM application framework), which enabled arbitrary Python execution. The operator then performed reconnaissance, credential harvesting across multiple providers (OpenAI, Anthropic, AWS, GCP, Azure, and Chinese cloud providers), local database exfiltration, and lateral discovery to enumerate internal services including MinIO object storage using default credentials (minioadmin:minioadmin). Self-correcting behavior was observed, including adaptive retry mechanisms that resolved failed login attempts within 31 seconds. The campaign ultimately pivoted to a separate production database server running MySQL and Alibaba Nacos, where the LLM leveraged known Nacos authentication bypasses to establish further access, demonstrating real-time adaptation and parallel multi-threaded credential scanning patterns characteristic of LLM-generated payloads rather than human operators.
