JADEPUFFER: Agentic ransomware for automated database extortion

Sysdig Threat Research Team documented the first observed case of fully autonomous ransomware driven end-to-end by a large language model, dubbed JADEPUFFER. The threat actor gained initial access via CVE-2025-3248, an unauthenticated remote code execution flaw in Langflow (an open-source LLM application framework), then executed a multi-stage extortion campaign targeting a production MySQL database. The LLM systematically enumerated the compromised host, harvested credentials across multiple providers (OpenAI, Anthropic, AWS, Alibaba, Tencent), enumerated MinIO object storage using default credentials (minioadmin:minioadmin) to access terraform-state and backup buckets, and pivoted to the intended target via exposed Nacos configuration services. JADEPUFFER's payloads exhibited self-narrating behavior with natural language reasoning and real-time adaptation, including recovery from failed login attempts within 31 seconds. The operation established persistence via crontab beaconing to attacker infrastructure every 30 minutes.
