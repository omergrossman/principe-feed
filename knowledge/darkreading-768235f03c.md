Cordyceps Campaign: Malicious Pull Requests Target Developer CI/CD Workflows

A coordinated campaign dubbed 'Cordyceps' has exploited CI/CD pipeline vulnerabilities across multiple high-profile open-source projects, including Microsoft Azure Sentinel, Google's AI Agent Development Kit, Apache Doris, Cloudflare Workers SDK, and Python's Black formatter. The attack leverages compromised pull requests to inject malicious code into developer workflows, demonstrating continued targeting of supply chain infrastructure.
